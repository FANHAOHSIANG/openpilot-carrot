This isolated branch stages the fusion Panda steering guard, TX/forwarding hooks, explicit vehicle flags, and matching native regression fixtures. The reserve module is connected to the staged controller behind a separate default-off parameter for offline regression. No settings UI or device release is provided. HkgPhase1Assist remains model-only and passive recording remains separate. This branch must not be installed on C4 or used on public roads. Existing Test and fusion branches remain unchanged.

Acceptance: native compilation; production TX and forwarding checks; driver override, stale/invalid wheel data, request interruption and separate angle/torque authorization; existing B1 and vehicle-family regressions; controller-to-Panda parity; controlled bench/HIL verification. Do not merge on the strength of CI alone. Existing scoped HKG workflow intentionally requires unchanged Panda code; its scope must not be bypassed. Controller integration is staged, not validated. Native and HIL compatibility are not established; Sorento-specific camera-paced fixtures remain excluded because their controller cadence changes have not been ported. The four-family synthetic tests now use the independent explicit reserve switch, initialize the camera flag before controller construction, and verify production admission rather than forcing the supported flag. These tests are not vehicle identification or B1 hardware validation.
