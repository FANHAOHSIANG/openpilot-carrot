# 外部導航 ROUTE 誤減速修正

外部導航路線在高速直線路段有時會出現一小段橫移後折回。C4 先前會把那段短折線算成彎道，提早降低 `ROUTE` 速度上限。這次在 Carrot 的外部導航路線預覽內，將符合距離、橫移幅度與首尾航向條件的折返從地圖曲率估算排除。視覺彎道調速仍會獨立評估前方道路。

## 使用

更新 C4 的 `test/carrot-wip-upstream-20261104` 到包含本修正的提交，即可沿用現有路線減速設定。App 投屏及 Google NOO 介面更新另外由 Carrot Bridge APK 提供。這項修正沒有新增開關。

## 驗證

- 144 項離線測試涵蓋路線曲率、CarrotMan／CarrotServ 整合、OSM、視覺彎道與過彎加減速。回歸測試包括外部導航短折返，以及超出視覺比對範圍的正常曲線。
- 同一趟紀錄採用固定輸入回放。在第 91 段的 `ROUTE` 時間窗，重算的最低路線上限由 61.3 提高至 85.1 km/h。第 89 段對照時間窗維持 67.6 km/h。
- 這些數字是離線估算的路線速度上限。實車速度、減速度和制動反應待確認。
