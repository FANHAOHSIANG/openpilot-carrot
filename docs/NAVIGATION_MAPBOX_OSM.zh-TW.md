# 座標導航與 OpenStreetMap 地圖

在「導航地圖」分別輸入緯度、經度，例如新竹附近的 `24.80`、`120.97`。按「確認座標並傳送」後再核對一次，確認才會設定目的地。Google Maps 分享入口也可傳送目的地座標。地址地理編碼已停用。

最愛儲存在車機上，可用名稱與座標新增或編輯。舊版僅有地點 ID 或地址文字的最愛，請先補上座標。「結束當前導航」清除本頁目的地；外部導航行程由來源 App 結束。

座艙以 Leaflet 顯示 OpenStreetMap 底圖。收到車機有效的位置、路線與指引時，地圖會顯示轉彎與剩餘距離。拖曳可瀏覽地圖，按「目前位置」恢復跟隨。OSM 停車區圖層可在設定內選用，圖資標示的停車格沒有即時空位資訊。

模型圖資與路徑規劃沿用車機的 mapsd 與 Mapbox 設定，相關用量仍依供應商方案計算。觀看端只載入可見範圍的 OSM 圖磚，保留署名及瀏覽器快取。[OSM 圖磚使用政策](https://operations.osmfoundation.org/policies/tiles/)
