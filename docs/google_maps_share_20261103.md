# Google Maps 分享目的地 → Carrot → HUD

此版本只匯入單一目的地；Carrot 重新計算路線，並使用現有 HUD 模式 7。
不讀取 Google Maps App 內部導航狀態，不同步其選定路線，不修改模型或控制。

## 第一次配對

在 C4：

```bash
cd /data/openpilot
python3 tools/navigation/pair_google_share.py
```

在手機開啟原本 Carrot Web 相同主機與連接埠的 `/navigation/share`。
例如原網頁是 `http://192.168.0.25:7000/navigation`，分享頁就是
`http://192.168.0.25:7000/navigation/share`；請使用自己的 C4 位址。
輸入終端機產生的六位數配對碼，10 分鐘內有效，成功使用一次後失效。
新碼會撤銷舊配對。配對資料位於持久化的 Carrot state 目錄，權限 0600；
伺服器只保存密鑰雜湊。不要把配對碼貼給別人。

## 先直接測試

1. Google Maps 選一個地點，按分享、複製連結。
2. 在分享頁貼上，按「解析地點」。
3. 若只有地名，按「搜尋候選地點」並選擇正確地址。
4. 核對顯示的地點與座標，按「確認，傳送到 Carrot」。
5. 點「查看 Carrot 路線與地圖」，等待 ready；HUD 沿用模式 7。

解析連結不會自動修改目的地。若無法展開短網址，貼完整地點網址或直接搜尋地址。
`/@緯度,經度` 是地圖視角，不能當成目的地。只有明確的目的地座標或單一 POI
座標才可直接確認；多個地點、Place ID 等無座標連結需要使用者搜尋確認。

## iPhone 捷徑（手動建立）

名稱：傳送到 Carrot。開啟「在分享表單中顯示」，接收 URL 與文字。

1. 如果收到多個項目，先取第一個 URL/輸入項目。
2. 加入「URL 編碼」，輸入選「捷徑輸入」（或上一個取出的 URL）。
3. 加入「文字」，內容為：
   `http://你的C4位址:原連接埠/navigation/share#url=` 後接「URL 編碼」的結果變數。
4. 加入「打開 URL」，輸入選上一步的文字。

Google Maps → 地點 → 分享 → 傳送到 Carrot → 解析地點 → 確認。
網址片段只用來帶入待確認連結，讀入後會從瀏覽器網址移除；分享網址和配對密鑰
不放在伺服器 query log。配對在瀏覽器保存，所以要使用同一瀏覽器、同一 C4 網址。
分享頁的「設定 iPhone 捷徑」會依目前網址提供可複製的網址前綴。
目前提供操作說明，沒有宣稱已產生可一鍵安裝的 Apple 簽署捷徑。

## 驗證與限制

- Python 測試覆蓋配對、過期、撤銷、限流、確認寫入、座標驗證和每一步轉址限制。
- JS 流程測試覆蓋片段移除、不自動送出、文字安全顯示、明確確認及清除配對。
- 短網址網路解析和 iPhone 分享表單仍需用實際裝置驗證；不宣稱支援所有 Google 網址。
- 目的地有儲存不等於路線已建立。仍需 Mapbox、有效位置和啟動中的導航服務。
- 若外部導航正在控制路線來源，既有 Carrot 優先規則保持不變。
- 無新 Google API 金鑰需求；使用既有 Carrot/Mapbox 設定。

本次執行環境無法解析 Google 短網址的 DNS，公開短網址實連測試未完成。
轉址處理已用模擬回應驗證；真實 Google 短網址與 iPhone 分享操作需安裝後驗證。
