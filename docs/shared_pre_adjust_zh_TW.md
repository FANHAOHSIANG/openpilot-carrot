# 三導航共用轉彎預調（wide.79 測試）
高德車機版、高德一般版、Google NOO 都經由相同導航狀態與有效轉彎資料接入。
App 的原生「智慧／預調速」開關授權共用轉彎預調；車端 AutoNaviSpeedCtrlMode 必須大於 0。
共用預調採用既有 AutoTurnControlSpeedTurn（10–80 km/h 範圍）、AutoTurnControlTurnEnd 與 AutoNaviSpeedDecelRate 計算的當前轉彎減速曲線；不新增固定匝道速度、不改道路速限、不提高巡航設定。
這項共用預調獨立於 AutoTurnControl 模式開關（不啟用轉向或方向燈），要停用請關閉 App 預調或導航減速主開關。其他既有 ATC／曲率調速設定保持原有作用。
僅處理已驗證左／右轉與急左／右轉代碼 12、13、16、19；未辨識、直行、抵達、僅出口提示不猜成轉彎。導航結束、偏離路線、切換來源、舊引導或權限過期即撤銷。狀態和轉彎來源時間都必須新鮮，期限取兩者最早到期者；按發送前年齡加接收後經過時間限制兩秒（不含網路傳輸延遲）。
高德車機版仍可提供 wide.78 原生匝道策略；高德一般版／Google 主線限速不足，沒有等效匯入恢復。轉彎完成後共用限制解除，後續由原有巡航與其他限制處理。較低測速／曲率／ATC 限制優先。
需安裝 wide.79 App 並更新本分支後重啟 comma。離線測試不等於三地圖實車驗收。本版請小心測試；正式 wide.77 不變。
