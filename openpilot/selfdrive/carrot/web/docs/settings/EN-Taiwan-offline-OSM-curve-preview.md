## Taiwan offline OSM curve preview

`OsmCurveSpeedEnabled`

Defaults ON. Without a navigation route, uses resident OSM roads for Taiwan, Penghu, Kinmen and Matsu. Downloads automatically while parked on unmetered Wi-Fi. Requires turn-speed mode 2/3. Stops at forks; position, heading and vision must agree. Adds a speed ceiling, not navigation guidance.
