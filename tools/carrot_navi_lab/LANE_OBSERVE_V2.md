# 車道觀察 v2 — 事件顯示試用

停車後開啟 C4 網頁 `http://<C4-IP>:7000/lane-observe.html`，按開始連線。預設「自動」：有新鮮、有效的導航車道事件才顯示提示區；撤銷、資料過期、斷線清除。可關閉提示區或持續觀察。原本視覺俯視圖和記錄/匯出保留。請乘客操作及觀察，不在駕駛時操作。

這是獨立測試頁，不是模式七的主 HUD，也不是 Android wide.88 APK。使用現有 raw_multiplex 唯讀資料流，不新增 C4 常駐服務、不增加模型、不修改控制或導航發布。使用 87 版原有資料來源。

已知 11/27 的 C4 實車記錄可見 count=3、4，但 available 陣列空白；沒有可靠推薦方向或自車絕對車道序號。不由 count、轉彎方向或原始旗標猜測推薦，僅顯示缺資料或未驗證。視覺局部候選與導航引導並列，不宣稱空間融合。

記錄包含 schema 2 presentation 快照，仍標記 control_usable=false。關閉或隱藏頁面停止訂閱。匯出 JSONL 後提供回饋。
