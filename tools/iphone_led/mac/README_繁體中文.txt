LED Mac Test 0.4.1 · YS 系列 LOY PLAY 與 Carrot HUD 連動測試
2026-11-05

開始測試
1. 停車後結束舊版工具，解壓新版並雙擊 START.command。
2. 讓手機的 LOY PLAY 和 CP 搭子先與屏幕斷線，屏幕保持通電。
3. 按「掃描藍牙」，選擇 YS5255140425，按「連接屏幕」。
4. 連線後預設送出關閉屏幕指令，請按「開啟屏幕」。輸入解析度 96x16 並按「套用」。這是 YS5255140425 已目視確認能顯示 TEST 的設定。
5. 按 TEST，再試「左轉彎」、「右轉彎」、「減速中」、「暫停一下謝謝」、「謝謝」和「前方塞車」。
   同一顆電源按鈕會顯示「開啟屏幕」或「關閉屏幕」。熄屏時按「開啟屏幕」再試 TEST。
6. 按「我看到正確畫面」或「畫面異常」，再下載診斷紀錄。
   若連不上、畫面沒有反應或顯示錯誤，也可直接下載 LED_diagnostics.zip。

若無法雙擊，在終端機輸入 bash 和一個空格，把 START.command 拖入再按 Enter。
首次安裝套件時需要網路和 Python 3.10 以上。啟動時會自動安裝 HUD 解碼套件 pycapnp。
macOS 詢問藍牙權限時，請允許終端機／Python。

Carrot HUD 連動測試
1. 保持 C4、Jetlink、CarrotMacHUD 運行。在 Mac 上按「只讀預覽」。
2. 停在 P 檔時踩放煞車、打左燈及右燈。看預覽頁的車況筆數和欄位是否跟著變。
3. 停止預覽。確認已連接 LOY、開屏及套用 96x16，再按「連動到屏幕」。
4. 停車確認踏板、檔位和燈號文字。動態減速請在封閉場地測試。完成後按「停止連動」並下載診斷。

D 檔踩煞車或持續減速會顯示「減速中」，回充和其他來源的持續減速都包含在內。
起動條件為車速至少 5 km/h，加速度不高於 −0.50 m/s² 持續 0.30 秒。
加速度回到 −0.25 m/s² 或更高，或速度低於 3 km/h 時，結束減速顯示。
左右方向燈顯示「左轉彎」和「右轉彎」。P 檔雙黃燈顯示「暫停一下謝謝」，D 檔雙黃燈顯示「謝謝」。D 檔雙黃燈且急減速持續 0.3 秒顯示「前方塞車」。急減速初始門檻為 −2.0 m/s²，回到 −1.5 m/s² 解除。燈號優先於一般減速。
HUD 資料過期或手動停止時，工具會在藍牙連線可用時送清屏指令。BLE 掉線時請目視確認是否留有畫面。
連動只讀 Mac 已收到的 HUD 車況，並用 BLE 更新屏幕。啟動後要手動選擇預覽或屏幕連動。

連線與回覆
YS 設備名稱、FFF0 服務、FFF2 無回應寫入和 FFF1 通知共同決定是否啟用試送。
連線會訂閱 FFF1 並查詢裝置和屏幕電源狀態。
未輸入解析度時，TEST 試送 16 × 8 像素的小區域。完整畫面使用你輸入的實際像素尺寸。
電源按鈕會送出開啟或關閉指令，再查詢狀態。連線時若沒有收到狀態，第一次按會送開啟。
若屏幕只確認指令收到，按鈕會依最後送出的動作切換，並標示收到指令的結果。
工具把 Mac 送出、屏幕回覆和目視結果分開記錄。畫面結果請以實際屏幕為準。
單張顯示正常後，可用連續測試和重連測試檢查穩定性。

LOY 的文字與箭頭使用暫時繪圖模式。斷線時工具會嘗試退出該模式。
屏幕可能回到原本節目或保留最後畫面。亮度只有按「設定亮度」才會送出。
「檢查藍牙通道」只列出 BLE 服務與特徵，供下載診斷。
診斷含所選設備、通道、屏幕回覆、錯誤與手動目視結果。
連動診斷含 HUD 收到的車速、加速度與燈號，及畫面切換紀錄。

0.3.0 新增設定
在「文字顏色與特效」修改各車況文字、顏色、效果、速度，按儲存。靜態、閃爍、雙閃、左右跑馬燈、呼吸、自動換色可獨立設定。停止連動後可選車況並按預覽特效。動畫透過藍牙持續更新，效果與穩定性需實際確認。
在試送畫面輸入自訂文字並按「顯示自訂文字」，連動期間可修改；有有效車況提示時優先顯示車況，恢復正常時再顯示自訂文字。HUD 資料過期時清屏，不會恢復自訂文字。按「清屏」取消自訂文字，車況提示仍有優先權。自訂待機文字僅在本次程式執行期間保留。
首次手動連線後，記住屏幕與套用的解析度，下次啟動或意外斷線會嘗試自動重連。手動按斷線後本次不自動重連。每次連上會送出關閉屏幕指令，重新使用時請按開啟，開屏後會自動啟動車況連動。

0.4.0
在「五組自訂文字」可分別儲存文字、顏色、效果和速度；先按儲存五組設定，再按對應顯示。重啟後文字設定保留，需重新選取顯示的組別。
屏幕連接、開啟及解析度就緒後，程式會自動啟動 Carrot HUD 屏幕連動。按停止連動會暫停自動啟動；再按連動到屏幕可重新啟用。開關屏幕依然可在連動期間操作，關屏後停止連動，開屏後重新自動連動。
跑馬燈改為完整畫面更新，減少反覆清屏閃爍；不同屏幕的位圖處理可能有差異，請實際觀察是否殘影或閃爍。

預設屏幕解析度為 96 × 16，可在連線後手動更改。

0.4.1：五組自訂文字增加「加粗／一般」選項。按儲存後再按顯示，舊文字會保留。96 × 16 下筆畫較多的字若黏在一起，可改回一般或減少文字字數。
