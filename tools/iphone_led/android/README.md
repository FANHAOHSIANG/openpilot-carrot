# Carrot LED Android 0.1.0

Android 8.0 以上的原生 App。沿用 C4 `/carstate` 橋接與 LOY PLAY FFF0/FFF1/FFF2 BLE 協定；C4 不需另裝 Android 專用橋接，不發送車輛控制／CAN 指令。

## 安裝及開始

1. 將 `CarrotLED-0.1.0.apk` 傳到 Android 手機，點開安裝；若系統詢問，允許當次使用的檔案管理器安裝此來源的 App。
2. C4 與手機接同一區網，填入 C4 IP 與既有固定橋接金鑰。不是 iPhone／Apple／Google 帳號密碼。只支援私人 IPv4 位址。
3. 允許附近裝置、通知；Android 11 以下掃描 BLE 另需位置權限和系統位置開關。
4. 讓 iPhone、Mac、LOY PLAY 先斷開屏幕；按「開始背景連動」。既有 YS5255140425 屏幕會自動連線，其他 FFF0 屏幕可掃描後手動選擇。連線後送開屏並恢復自動車況。
5. 確認前景實際可開關／清屏／顯示車況，再測試切換 App、鎖屏與熄屏。通知列可清屏或停止；「清屏」會取消自訂文字並暫停車況，按「恢復自動顯示車況」才恢復。

此版為側載測試簽署 APK，不是 Play 商店正式發布版。更新時需同一簽署金鑰；不要刪 App，以保留設定。最低 Android 8（API 26），target/compile SDK 36。沒有開機自動啟動；使用者需在 App 按開始。系統強制停止／程序死亡後不會宣稱仍在連動。

## 功能

- `connectedDevice` 前景服務、常駐通知、連動期間 partial wake lock；切換 App 不停止服務。每次連動上限 8 小時，需重新開始；停止時釋放資源。
- C4 每約 200 ms 嘗試讀取，HTTP 回覆超過 900 ms 捨棄；資料過期或無效則嘗試清屏，不讓自訂文字蓋過失效狀態。Wi-Fi 暫斷時重試。藍牙斷線後嘗試重連已選設備。
- D 檔煞車或持續動能回收減速優先於單邊方向燈。回收門檻：速度至少 5 km/h、加速度 ≤ -0.5 m/s² 持續 300 ms；速度低於 3 km/h 或加速度 ≥ -0.25 解除。
- 急減速（≤ -2.0 m/s² 持續 300 ms）加雙黃燈：減速中／前方塞車每 2 秒交替；R 檔倒車；P 檔雙黃燈暫停一下謝謝；D 檔普通雙黃燈謝謝。
- 各車況與五組自訂文字可分別儲存文字、調色盤顏色、字型、字重、靜態／閃爍／左右跑馬燈／呼吸／換色。車況結束後恢復選用的自訂文字。
- 字型可選系統樣式或匯入一份 TTF／OTF（最多 20 MB，請使用有授權字型）。中文 fallback 可能讓不同系統樣式看起來相同。
- 預設 96 × 16 燈珠；文字高度目標 16 排、字寬 100%。文字空白保留，不會將所有燈珠亮起；全亮測試可確認硬體。變更尺寸前須停止服務，避免傳送途中混用尺寸。
- 本版未移植 iPhone 的圖案效果；文字動畫仍為手機逐格傳送，並非已破解的屏幕原生動畫，不能保證原生跑馬燈的流暢度。

## 背景與資料保護限制

原生服務比 iPhone 一般背景輪詢適合此架構，但廠商省電／Doze／使用者強制停止仍可能中斷。必要時在系統 App 電池設定允許背景使用。不要以「通知仍存在」當作實際屏幕更新的證據。

藍牙使用完整封包序列傳送，最新畫面取代尚未開始的待送畫面，避免無限堆積；回呼逾時重連。藍牙連線／訂閱成功不等於屏幕顯示回讀確認。完全斷線或系統暫停時無法保證清屏；停止服務時最多等待約 1.8 秒送出清屏再斷開。

金鑰以 Android Keystore AES-GCM 保存在 App 私有儲存，停用系統備份，不寫入通知或日誌。C4 既有橋接仍是私人網路 HTTP，網路傳輸本身沒有加密；不跟隨 HTTP 重新導向。通知只顯示連線狀態，沒有金鑰／IP。

## 建置與測試

- Android Studio 開啟本目錄，使用 JDK 17、Gradle 8.11.1、AGP 8.10.1；或下列不依賴 Gradle 的 SDK 命令列建置。
- 安裝 Android SDK platform 36、build-tools 36.0.0、JDK 17。
- `ANDROID_SDK_ROOT=/absolute/sdk ./build-apk.sh`
- `./test-core.sh`：離線驗證煞車／回收／倒車／雙黃燈優先順序與交替，以及 LOY 電源、清屏和像素封包。
- 命令列建置使用 `~/.android/debug.keystore`；可用 `CARROT_ANDROID_KEYSTORE` 指定保留的測試簽章。簽章檔不得提交 Git。

停車實測清單：第一次權限拒絕／允許、前景開關屏與清屏、各車況優先順序、自訂文字恢復、五組儲存重開、字型匯入與空格、切 App 2 分鐘、鎖屏 5 分鐘、熄屏 15 分鐘、C4 Wi-Fi 中斷／恢復、屏幕斷電／恢復、通知停止後不再顯示車況。長時間背景和 LOY 實機畫面尚待驗證。
