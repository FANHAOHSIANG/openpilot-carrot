iPhone / C4 / LOY LED 區網連動原型 0.16

架構：C4 只讀車況橋接 → 區網 → iPhone → 藍牙 → 96 × 16 LED。
這是 Xcode 原始碼，需用 Mac 的 Xcode 簽署並安裝到 iPhone。

本版：
- 車況觸發左右轉彎文字與移動箭頭，其他車況文字和優先順序沿用原版。
- 五組自訂文字可選顏色、字重與靜態、閃爍、左右跑馬燈、呼吸、自動換色、左右動態箭頭、波浪、愛心及警示圖案。圖案以參考影片為靈感，非逐格複製。
- 使用者輸入的半形空格會以不換行空格渲染，保留字間距，不修改原本儲存的字詞。
- 藍牙、C4 嘗試自動連接；金鑰保存在 iPhone 鑰匙圈。C4 固定金鑰和自動啟動已整合至 carrot-wip，詳見上層 README.md。
- 車況優先於自訂文字；資料失效時嘗試清屏。

注意：此環境無 Xcode，Swift 新版尚未編譯與實機測試。請先停車測試文字空格、箭頭方向、效果、切換延遲、殘影及斷線清屏。完整畫面逐格更新能否避免閃爍或殘影，取決於 LED 實際行為。iOS 可能暫停背景網路與動畫，不能保證背景更新或清屏。BLE 回覆尚未確認，斷線時畫面可能保留。

C4 保留 /data/iphone-led/token 的既有固定金鑰；在行車介面啟動時由 manager 管理橋接程序，異常退出會嘗試重啟，離開行車介面時停止。HTTP 僅限可信私人網路，金鑰和車況不加密。GitHub 合併不會自動更新 C4 或重新安裝 iPhone App。

安裝更新（0.14 必須重新產生專案，不能只替換舊版單一 Swift 檔）：
1. 在 Mac 解壓新版到新資料夾，保留整個目錄，包含 LiveActivity 子資料夾。
2. Terminal 進入有 project.yml 的目錄。若未安裝 XcodeGen，先執行 brew install xcodegen；再執行 xcodegen generate。
3. 開啟 CarrotLEDProbe.xcodeproj。在主 App 與 CarrotLEDLiveActivity 兩個 Target 的 Signing & Capabilities 選相同 Apple 開發團隊、勾選 Automatically manage signing。
4. 主 App 的 Bundle Identifier 改成你原本已安裝的值，保留設定與鑰匙圈；extension 必須使用同一前綴再加 .liveactivity。不要移除舊 App。
5. Scheme 選 CarrotLEDProbe、裝置選 iPhone，按 Run 安裝。只更新 iPhone，不需變更 C4。
本版最低 iOS 16.2；「背景行車連動」測試按鈕只允許 iOS 26 以上開始。

0.5.1：僅當實際安裝 App 的 Info.plist 宣告 bluetooth-central 時才啟用藍牙狀態恢復。若 Xcode 使用其他 Info.plist，改為前景連線以避免啟動時例外；要使用背景藍牙，請檢查 Target → Signing & Capabilities → Background Modes 勾選 Uses Bluetooth LE accessories。

0.6：LED 通知訂閱確認後顯示連線狀態、自動送開屏並啟用車況；C4 尚未有有效資料時不應顯示車況。新增清除屏幕（暫停車況及自訂畫面），重新開啟自動顯示車況可恢復。新增 96×16 白色全亮測試。鍵盤工具列有完成，亦可向下滑動收起。字形依實際墨跡高度放大、長文字跑馬燈不壓縮而是整段移動。所有畫面未經 Xcode 編譯及屏幕實機驗證。

0.7 字型選擇：車況訊息可選標準、圓體、等寬或襯線；五組自訂文字各自保存字型與字重。既有沒有字型欄位的設定會預設標準。某些中文字可能由系統後備字型顯示，四種風格差異以屏幕實測為準。新版尚未在 Xcode 編譯或 LED 實測。

0.8：車況文字可編輯並儲存；可選 iPhone 實際提供的字型，中文需選支援中文字的字型（例如 PingFang TC，依裝置提供為準）。可調屏幕像素、字高及字寬。跑馬燈每格先清屏再重繪，以排除畫面累積；這是藍牙逐格繪製，尚非屏幕原生跑馬燈，流暢度及閃爍需實機驗證。修改屏幕寬高前請確認真實燈珠尺寸，原設定為 96×16。文字和設定儲存於 iPhone。請停車測試。本版本尚未經 Xcode 編譯或 LED 測試。

0.9：新增倒車提示，R 檔預設顯示「倒車，請注意」，文字、顏色、動畫均可編輯。倒車時優先顯示倒車訊息，離開 R 檔恢復其他車況提示。每種車況均可設定並儲存文字、顏色和動畫；按「儲存所有車況設定」後生效，會沿用 0.8 已儲存文字。車況共用一個字型選擇；五組自訂文字各自可選字型。明確顯示「選擇字型」按鈕，列出 iPhone 可用且通過部分繁體字涵蓋測試的字型；實際字形與支援字元依系統為準。

屏幕實際規格：橫 96 顆 × 直 16 顆，共 1536 顆；實體約 600 × 120 mm。屏幕寬高請維持 96 和 16。文字高度是目標像素列數，16 代表盡量使用 16 排；文字寬度 100% 為基準，超過 100% 會拉寬，靜態文字放不下時會自動縮窄。文字、箭頭和空白處不會讓每顆燈同時亮起。

先重新以 Xcode 安裝 iPhone App；不需要更新 C4。請停車測試 R 檔、左右燈、雙黃燈、煞車、效果與字型。此版本在製作環境沒有 Xcode，尚未在 iPhone 編譯或實機測試。動態效果由 iPhone 逐格傳送，不是已確認的屏幕原生播放，iOS 背景執行及斷線時不能保證即時顯示或清除。

0.10：D 檔踩煞車或偵測到持續動能回收減速時，優先顯示可編輯的「減速中」，即使同時打方向燈或雙黃燈也一樣；解除後依當下車況恢復。沿用原本減速門檻：時速至少 5 km/h、加速度不高於 -0.50 m/s² 並持續約 0.3 秒，並有解除遲滯，非任何程度的減速都會觸發。R 檔倒車及 P 檔雙黃燈規則維持不變。依最優先規則，急減速並打雙黃燈時「減速中」會蓋過「前方塞車」；現有門檻下「前方塞車」將不會出現。尚未經 iPhone 編譯或實車測試。

0.11：更新 0.10 的優先順序：D 檔同時急減速和打雙黃燈時，先顯示「減速中」，然後每 2 秒與「前方塞車」交替。曾偵測到急減速後，只要雙黃燈與煞車／減速狀態持續，交替即持續；雙黃燈關閉、煞車／減速結束或車況資料中斷時，交替結束並依目前車況恢復。一般減速同時打單邊方向燈仍優先顯示減速中。兩個提示仍各自使用可編輯的文字、顏色和效果。急減速沿用速度至少 5 km/h、加速度不高於 -2.0 m/s² 且持續約 0.3 秒的原判斷。iPhone 尚未編譯或實機測試。

0.12：車況文字與五組自訂文字的顏色都改用 iPhone 系統調色盤。按「文字顏色」旁的色塊，即可選擇顏色，並使用系統提供的色譜、色格或滑桿。車況修改後按「儲存所有車況設定」；自訂文字修改後按該組「儲存」。舊版已儲存的顏色會沿用；若舊資料的顏色格式無效，恢復為預設黃橘色。螢幕實際顏色受亮度和燈珠影響。此版本尚未以 Xcode 編譯或在 iPhone 和 LED 屏幕實測。

0.13：將車況與自訂文字的字型選單改成獨立選擇頁。開啟時以當時選取字型定位；點選僅變更勾選狀態，按「套用」才確認；取消或滑動關閉不更改原設定。清單順序固定，可搜尋名稱，車況資料更新不重新建立選取流程。字型按鈕保留固定文字高度，減少主畫面位置因字型名稱長短改變。車況字型套用後自動儲存，自訂文字仍須按原本的「儲存」按鈕。

字型選擇驗證：連接 C4 後開啟字型頁，滑到清單中下段停留，點選多個字型確認位置不跳回頂端；按取消確認原字型不變；按套用後重新開啟確認定位到已選字型；車況字型與五組自訂文字均需測試。製作環境沒有 Xcode，尚未完成編譯及 iPhone 實機驗證。


0.14 行車即時動態（實驗功能）：
- 先開 App，確認屏幕已連線、C4 車況持續更新、自動顯示車況已開啟，再按「開始行車即時動態」，之後切換 App。
- 使用 ActivityKit + WidgetKit extension，顯示於鎖定畫面及支援的動態島。無遠端推播、無假音訊／定位保活，不需要 App Group。
- iOS 26+ 的 Live Activity 可改善背景藍牙權限；它不是讓 HTTP 輪詢與動畫無限執行的授權。即使畫面仍存在也不代表車況正更新。
- 最後收到車況超過 0.9 秒，Activity content 以 staleDate 標示過期；系統呈現時機仍由 iOS 決定。不在即時動態顯示舊煞車或轉向字詞。
- App 有執行機會時，每約 0.33 秒檢查車況過期並嘗試清屏；超時才回到 App 的舊 HTTP 回覆會捨棄。iOS 暫停 App 或藍牙斷線時，無法保證實體 LED 已清除。
- 未開始行車即時動態時，切背景會嘗試清屏並暫停輪詢；回前景重新取新資料。結束／系統終止即時動態時，同樣不再允許背景輪詢。App 重啟不自動重開行車即時動態。
- 清屏按鈕維持原功能：暫停自動車況並取消自訂文字，不因即時動態而重新啟用。停止即時動態不停止前景車況使用。

停車驗證（實車未完成，請分別記錄）：
A. 前景開始 session，切到其他 App 2 分鐘：確認實體 LED 回應車況，而非只看動態島。
B. 鎖屏亮著、鎖屏熄屏各 5 分鐘：觀察連動／動畫是否停止，再回 App 確認恢復。
C. 中斷 C4 Wi-Fi、關閉屏幕藍牙：確認過期與斷線標示；若 LED 保留舊畫面，記錄當時 App 狀態。
D. 結束即時動態再切背景：不得繼續用舊車況刷新；回前景應重新收資料。
E. 關閉即時動態權限或重啟 App：應顯示未啟動／需要授權，不宣稱已持續連動。
此功能沒有修改 C4 車輛控制、橋接金鑰、LED 字體或事件優先順序。無法承諾背景持續時間；強制關閉 App 後不能繼續連動。

新版快捷頁：車況七項標題為 R檔、左方向燈、右方向燈、煞車、雙黃燈、感謝燈、急煞雙黃燈。內部狀態代號與原存檔保留。各項文字、字型、加粗、顏色、動畫獨立儲存。車況按「顯示」手動預覽 5 秒，期間暫停自動輸出，結束後恢復原模式；清屏會取消預覽、自訂與自動顯示。自訂文字按顯示後保留為待機文字，啟用自動時車況優先。快捷頁與編輯設定分開，顯示 C4、藍牙與目前送出內容。顯示內容不是屏幕回讀確認。請停車操作。
Android 補齊左右動態箭頭、波浪、愛心、警示圖案，共 11 類效果；各平台字型不同，中文字可用匯入字型調整。動畫仍為逐格藍牙輸出，非確認的原生跑馬燈，流暢度需實機驗證。

0.16 自動背景連動：
預設開啟「自動啟動背景連動」。App 在前景、屏幕已連線、自動車況開啟，且 C4 資料未超過 0.9 秒時，會自動開始行車即時動態，不用另按開始。失敗最多每 30 秒再嘗試；仍可按立即啟動。停止或系統結束／關閉即時動態後會關閉並記住自動啟動偏好，避免立即重開；可自行重新開啟開關。首次啟動先結束遺留的即時動態，再等待新的有效車況。
開啟 App 等到顯示已開始後再切背景；不提供 iPhone 開機自啟、強制結束後自動喚醒，也不保證 iOS 永久不暫停。使用者已回報前版背景連動實測正常，本版自動啟動改動仍待實機確認。Android 本來已有前景服務，此次未變更 Android。
