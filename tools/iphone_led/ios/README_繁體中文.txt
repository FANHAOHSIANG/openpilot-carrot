# Carrot LED 方塊介面更新

Android 0.1.5 / iPhone 0.22。C4 橋接與金鑰沿用，更新手機 App 即可。

- 深色介面、琥珀色重點，首頁用醒目方框呈現最近送出的內容。
- 快捷分成「車況」「自訂文字」「眼睛動畫」，整張方塊可點選顯示。iPhone 兩欄，Android 依寬度排列；寬車機左側保留狀態及控制。
- 一顆電源鈕切換開關：開啟綠色、關閉黑色、未連線灰色。這是 App 指令狀態，不是屏幕電源讀回。
- 大型清屏鍵停止車況、自訂文字及眼睛動畫；重新開啟自動車況可恢復連動。
- 六種原創漸層眼睛：晶亮眨眼、靈動眼、惡魔眼、螺旋眼、火焰眼、機甲眼，可自行選色。iPixel 64×16 使用原生 GIF 循環播放（20 fps 素材）；其他尺寸／LOY 或關閉原生模式時，使用目標 5 fps 相容播放。實體流暢度待屏幕確認。
- 眼睛是獨立待機內容，不佔用五組自訂文字。車況提示優先，結束後恢復眼睛；自動車況開啟而 C4 資料失效時仍清屏。不連 C4 單獨測試眼睛，可先關閉「自動車況」。
- Android 預設開 App 自動啟動背景服務，首次需儲存 IP／金鑰並授權；設定頁可關閉自動啟動。iPhone 沿用開 App 自動重連與兩端就緒後啟動行車即時動態，背景設定可調整。
- 這是「開 App 自動開始」，不是開機自啟或強制關閉後自行復活。Android 每次最多 8 小時；iPhone 背景執行仍由系統管理。
- 字型、配色、五組自訂字詞與每項車況的獨立樣式均保留，編輯集中到「文字與動畫」。

安裝：Android 覆蓋安裝同簽章 APK；iPhone 解壓完整專案，執行 `xcodegen generate`，兩個 Target 選原開發團隊與 Bundle ID 後 Run。不需刪除舊 App。

驗證包含核心規則、眼睛優先切換／資料失效、點陣邊界與動畫、iPixel 封包、兩平台編譯，以及模擬器介面截圖。實體屏幕動畫、藍牙電源切換與特定車機背景限制需裝置確認。

## iPixel Color 64 × 16 適配（Android 0.1.3 / iOS 0.20）

保留 LOY PLAY，新增獨立 iPixel BLE 協定。C4 橋接與金鑰不用更換。

1. 先讓 iPixel Color 原廠 App、另一支手機或車機斷開這塊屏幕。
2. Android：先停止背景連動，到「連線設定」按「屏幕類型」，選 iPixel Color，再開始背景連動並掃描。iPhone：到「連線設定」選 iPixel Color，再掃描。
3. 從掃描列表選自己的屏幕。此類型會列出附近 BLE 設備；只有提供 FA02 寫入及 FA03 通知通道的屏幕才可完成連線。
4. 選擇 iPixel 時自動套用寬 64、高 16、字高 16。這款共 1024 顆燈，不能沿用 LOY 的 96 × 16。此適配限定 16 排，並非支援所有 iPixel 機型。
5. 先用「開啟／關閉屏幕」「燈珠全亮測試」「清除屏幕」驗證；再以自訂「左轉彎」「右轉彎」測試靜態、左右跑馬燈、閃爍及呼吸。
6. C4 有有效資料且自動車況開啟後，測試方向燈、煞車／動能回收、R 檔及雙黃燈。既有車況文字、顏色、字型與優先規則保留。

靜態、跑馬燈、閃爍、呼吸及變色使用 iPixel 原生文字效果，手機只在內容或樣式改變時重新傳送；箭頭、波浪、愛心及警示圖案仍為手機逐格繪製。不是把 iPixel Color 原廠 App 的全部圖庫、GIF 或音樂律動匯入。

字型會先由手機渲染成 16 排點陣，再送入屏幕。64 欄比原本 96 欄窄，較長靜態文字會縮窄，建議用跑馬燈或短字詞。跑馬燈以 8 像素區塊傳輸，末尾可能有少量補齊空白。

「藍牙已連線」表示通道已就緒；「已回覆接收」表示收到協定回覆，都不是讀回實體屏幕畫面的證明。文字上傳會等候完成回覆後才傳下一筆；失敗會顯示逾時並重連。清屏傳送暫存空白內容，不會使用清除屏幕 ROM 的指令。連線中斷時仍可能留下舊畫面。

驗證：Android APK 已編譯、沿用原簽章；37 項既有核心檢查與 6 種效果的上游封包對照，以及清屏／開關／ACK／尺寸邊界測試通過。iPhone 完整編譯以 GitHub Actions 或本機 Xcode 結果為準。**尚未在這塊實體 iPixel 屏幕驗證，這是供實機測試的適配版本。**

0.14 行車即時動態（實驗功能）：
- 先開 App，確認屏幕已連線、C4 車況持續更新、自動顯示車況已開啟，再按「開始行車即時動態」，之後切換 App。
- 使用 ActivityKit + WidgetKit extension，顯示於鎖定畫面及支援的動態島。無遠端推播、無假音訊／定位保活，不需要 App Group。
- iOS 26+ 的 Live Activity 可改善背景藍牙權限；它不是讓 HTTP 輪詢與動畫無限執行的授權。即使畫面仍存在也不代表車況正更新。
- 最後收到車況超過 0.9 秒，Activity content 以 staleDate 標示過期；系統呈現時機仍由 iOS 決定。不在即時動態顯示舊煞車或轉向字詞。
- App 有執行機會時，每約 0.33 秒檢查車況過期並嘗試清屏；超時才回到 App 的舊 HTTP 回覆會捨棄。iOS 暫停 App 或藍牙斷線時，無法保證實體 LED 已清除。
- 未開始行車即時動態時，切背景會嘗試清屏並暫停輪詢；回前景重新取新資料。結束／系統終止即時動態時，同樣不再允許背景輪詢。App 重啟不自動重開行車即時動態。
- 清屏按鈕維持原功能：暫停自動車況並取消自訂文字，不因即時動態而重新啟用。停止即時動態不停止前景車況使用。

停車驗證（實車未完成，請分別記錄）：
A. 前景開始 session，切到其他 App 2 分鐘：確認實體 LED 回應車況，而非只看動態島。
B. 鎖屏亮著、鎖屏熄屏各 5 分鐘：觀察連動／動畫是否停止，再回 App 確認恢復。
C. 中斷 C4 Wi-Fi、關閉屏幕藍牙：確認過期與斷線標示；若 LED 保留舊畫面，記錄當時 App 狀態。
D. 結束即時動態再切背景：不得繼續用舊車況刷新；回前景應重新收資料。
E. 關閉即時動態權限或重啟 App：應顯示未啟動／需要授權，不宣稱已持續連動。
此功能沒有修改 C4 車輛控制、橋接金鑰、LED 字體或事件優先順序。無法承諾背景持續時間；強制關閉 App 後不能繼續連動。

新版快捷頁：車況七項標題為 R檔、左方向燈、右方向燈、煞車、雙黃燈、感謝燈、急煞提示。內部狀態代號與原存檔保留。各項文字、字型、加粗、顏色、動畫獨立儲存。車況按「顯示」手動預覽 5 秒；自動車況開啟時，真正急煞會結束手動預覽，結束後恢復原模式；清屏會取消預覽、自訂與自動顯示。自訂文字按顯示後保留為待機文字，啟用自動時車況優先。快捷頁與編輯設定分開，顯示 C4、藍牙與目前送出內容。顯示內容不是屏幕回讀確認。請停車操作。

0.16 自動背景連動：
預設開啟「自動啟動背景連動」。App 在前景、屏幕已連線、自動車況開啟，且 C4 資料未超過 0.9 秒時，會自動開始行車即時動態，不用另按開始。失敗最多每 30 秒再嘗試；仍可按立即啟動。停止或系統結束／關閉即時動態後會關閉並記住自動啟動偏好，避免立即重開；可自行重新開啟開關。首次啟動先結束遺留的即時動態，再等待新的有效車況。
開啟 App 等到顯示已開始後再切背景；不提供 iPhone 開機自啟、強制結束後自動喚醒，也不保證 iOS 永久不暫停。使用者已回報前版背景連動實測正常，本版自動啟動改動仍待實機確認。Android 本來已有前景服務，此次未變更 Android。

0.17 動態島字詞：收合時顯示最近送出字詞（最多 5 字後加省略號），長按展開及鎖定畫面顯示完整文字（最多 16 字）。字詞變更會觸發即時動態更新，不傳送每一格 LED 動畫。斷線／資料過期時收合狀態優先提示異常；展開仍保留標示為最近送出的文字。清屏、全亮測試、開關屏幕也會顯示相應狀態。這是 App 送出內容，非 LED 硬體回讀；iOS 暫停或限制更新時可能延遲。兩個 Target 必須一起更新安裝；C4、Android 不需更新。

0.18 換字時展開動態島：
預設開啟「換字時展開動態島」。App 在背景、車況有效與屏幕已連線時，最近送出字詞變更會透過 ActivityKit AlertConfiguration 請求暫時展開；停留時間與縮回由 iOS 控制，不能指定秒數或保證每次都展開。自訂字詞與車況文字適用，同字詞、動畫逐格、清屏、開關屏、全亮測試不反覆展開；最少間隔 2 秒，期間只保留最新字詞。中斷、過期、回前景或關閉開關會取消待提醒，不回放過時事件。
使用隨包提供的短靜音提示音檔，不新增背景音訊保活或通知權限；系統是否震動或限制提醒依裝置設定。請重新 xcodegen generate，不能只替換 Swift 檔，新增 IslandAlertPolicy.swift 與 Resources/IslandSilent.wav 必須包含於主 App。缺少音檔時仍更新文字但不發展開提醒，避免意外使用系統預設聲音。C4 與 Android 不需更新。

0.19 動態島停止更新修正：
修正先前動態島約 1 秒更新，但快照僅 0.9 秒即過期的不一致。動態島改為沒有變更時每 5 秒送出狀態，字詞或連線狀態變更仍即時排入更新；畫面快照時效 15 秒，僅供 UI 使用。C4 與 LED 原有 0.9 秒有效性及清屏判斷不變，收到失效仍立即標示車況中斷。沒有新畫面超過快照期限時顯示「動態島更新逾時」，不再誤稱 C4 資料中斷。
ActivityKit 改為一次只執行一個更新；等待期間只保留最新內容，停止／重啟時取消舊工作，逾時快照及失效提醒不重新送出。App 顯示「最近完成提交」時間，這是 ActivityKit 呼叫完成時間，並非 iOS 確認已呈現畫面。
此版針對可確認的程式問題改善，不能保證繞過 iOS 更新或展開限制；需實機確認 LED 正常連動時，動態島字詞能否持續更新。C4 與 Android 不需更新。
