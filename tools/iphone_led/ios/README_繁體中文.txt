iPhone / C4 / LOY LED 區網連動原型 0.5

架構：C4 只讀車況橋接 → 區網 → iPhone → 藍牙 → 96 × 16 LED。
這是 Xcode 原始碼，需用 Mac 的 Xcode 簽署並安裝到 iPhone。

本版：
- 車況觸發左右轉彎文字與移動箭頭，其他車況文字和優先順序沿用原版。
- 五組自訂文字可選顏色、字重與靜態、閃爍、左右跑馬燈、呼吸、自動換色、左右動態箭頭、波浪、愛心及警示圖案。圖案以參考影片為靈感，非逐格複製。
- 使用者輸入的半形空格會以不換行空格渲染，保留字間距，不修改原本儲存的字詞。
- 藍牙、C4 嘗試自動連接；金鑰保存在 iPhone 鑰匙圈。C4 固定金鑰和自動啟動仍需另行安裝測試分支。
- 車況優先於自訂文字；資料失效時嘗試清屏。

注意：此環境無 Xcode，Swift 新版尚未編譯與實機測試。請先停車測試文字空格、箭頭方向、效果、切換延遲、殘影及斷線清屏。完整畫面逐格更新能否避免閃爍或殘影，取決於 LED 實際行為。iOS 可能暫停背景網路與動畫，不能保證背景更新或清屏。BLE 回覆尚未確認，斷線時畫面可能保留。

C4 的固定金鑰自動啟動方案在 GitHub 獨立測試分支，尚未安裝到 C4；HTTP 僅限可信私人網路，金鑰和車況不加密。既有臨時橋接仍可用；金鑰每次啟動會改變。

安裝更新：在 Mac 解壓，結束 Xcode，把 CarrotLEDProbe.swift 和 Info.plist 取代到原 Xcode 專案目錄，重新開啟專案並用 Xcode 對 iPhone 執行。只更動 iPhone 程式，不需變更 C4。請勿直接將 GitHub 測試分支併入正在行車的 C4。

0.5.1：僅當實際安裝 App 的 Info.plist 宣告 bluetooth-central 時才啟用藍牙狀態恢復。若 Xcode 使用其他 Info.plist，改為前景連線以避免啟動時例外；要使用背景藍牙，請檢查 Target → Signing & Capabilities → Background Modes 勾選 Uses Bluetooth LE accessories。

0.6：LED 通知訂閱確認後顯示連線狀態、自動送開屏並啟用車況；C4 尚未有有效資料時不應顯示車況。新增清除屏幕（暫停車況及自訂畫面），重新開啟自動顯示車況可恢復。新增 96×16 白色全亮測試。鍵盤工具列有完成，亦可向下滑動收起。字形依實際墨跡高度放大、長文字跑馬燈不壓縮而是整段移動。所有畫面未經 Xcode 編譯及屏幕實機驗證。

0.7 字型選擇：車況訊息可選標準、圓體、等寬或襯線；五組自訂文字各自保存字型與字重。既有沒有字型欄位的設定會預設標準。某些中文字可能由系統後備字型顯示，四種風格差異以屏幕實測為準。新版尚未在 Xcode 編譯或 LED 實測。

0.8：車況文字可編輯並儲存；可選 iPhone 實際提供的字型，中文需選支援中文字的字型（例如 PingFang TC，依裝置提供為準）。可調屏幕像素、字高及字寬。跑馬燈每格先清屏再重繪，以排除畫面累積；這是藍牙逐格繪製，尚非屏幕原生跑馬燈，流暢度及閃爍需實機驗證。修改屏幕寬高前請確認真實燈珠尺寸，原設定為 96×16。文字和設定儲存於 iPhone。請停車測試。本版本尚未經 Xcode 編譯或 LED 測試。

0.9：新增倒車提示，R 檔預設顯示「倒車，請注意」，文字、顏色、動畫均可編輯。倒車時優先顯示倒車訊息，離開 R 檔恢復其他車況提示。每種車況均可設定並儲存文字、顏色和動畫；按「儲存所有車況設定」後生效，會沿用 0.8 已儲存文字。車況共用一個字型選擇；五組自訂文字各自可選字型。明確顯示「選擇字型」按鈕，列出 iPhone 可用且通過部分繁體字涵蓋測試的字型；實際字形與支援字元依系統為準。

屏幕實際規格：橫 96 顆 × 直 16 顆，共 1536 顆；實體約 600 × 120 mm。屏幕寬高請維持 96 和 16。文字高度是目標像素列數，16 代表盡量使用 16 排；文字寬度 100% 為基準，超過 100% 會拉寬，靜態文字放不下時會自動縮窄。文字、箭頭和空白處不會讓每顆燈同時亮起。

先重新以 Xcode 安裝 iPhone App；不需要更新 C4。請停車測試 R 檔、左右燈、雙黃燈、煞車、效果與字型。此版本在製作環境沒有 Xcode，尚未在 iPhone 編譯或實機測試。動態效果由 iPhone 逐格傳送，不是已確認的屏幕原生播放，iOS 背景執行及斷線時不能保證即時顯示或清除。

0.10：D 檔踩煞車或偵測到持續動能回收減速時，優先顯示可編輯的「減速中」，即使同時打方向燈或雙黃燈也一樣；解除後依當下車況恢復。沿用原本減速門檻：時速至少 5 km/h、加速度不高於 -0.50 m/s² 並持續約 0.3 秒，並有解除遲滯，非任何程度的減速都會觸發。R 檔倒車及 P 檔雙黃燈規則維持不變。依最優先規則，急減速並打雙黃燈時「減速中」會蓋過「前方塞車」；現有門檻下「前方塞車」將不會出現。尚未經 iPhone 編譯或實車測試。

0.11：更新 0.10 的優先順序：D 檔同時急減速和打雙黃燈時，先顯示「減速中」，然後每 2 秒與「前方塞車」交替。曾偵測到急減速後，只要雙黃燈與煞車／減速狀態持續，交替即持續；雙黃燈關閉、煞車／減速結束或車況資料中斷時，交替結束並依目前車況恢復。一般減速同時打單邊方向燈仍優先顯示減速中。兩個提示仍各自使用可編輯的文字、顏色和效果。急減速沿用速度至少 5 km/h、加速度不高於 -2.0 m/s² 且持續約 0.3 秒的原判斷。iPhone 尚未編譯或實機測試。
