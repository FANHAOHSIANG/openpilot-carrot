# 胡蘿蔔車圖示與 LED 開屏動畫

Android 0.1.7（versionCode 8）／iPhone 0.24（App 與 extension build 24）。

- 使用選定的橘色實心胡蘿蔔車、綠葉和後窗 LED 圖示；沒有白色描邊。iPhone 桌面名稱為 Carrot LED；Android 包含圓形／自適應／主題單色圖示。
- 在 App 成功連線並自動開屏，或按電源由關轉開時，播放一次開屏動畫。16 排點陣保留胡蘿蔔車輪廓與三格 LED，先停留約 0.6 秒，再縮小往右開走，全程約 2.4 秒。
- 動畫結束後依「當下」車況、自訂文字／眼睛及自動車況開關決定內容；沒有內容時清屏。自動車況開啟而 C4 資料失效時仍清屏。
- 有效車況提示（包含煞車、方向燈及倒車）會取消開屏動畫；手動顯示、清屏、關屏或斷線也會取消，不會在稍後自行重播。正在傳送的封包仍需完成其傳輸邊界，不能保證零延遲。
- 重複送開屏不會重啟動畫；更新或切畫面本身不會播放。按自訂／預覽等按鈕喚醒屏幕時，以使用者選的內容優先。

## LOY PLAY 96×16 仍支援

舊屏幕請選「LOY PLAY」、寬 96／高 16，沿用既有 C4 金鑰。開關、清屏、車況、自訂文字與眼睛功能都保留；沒有改成 iPixel 專用 App。

LOY 開屏動畫採三色點陣與原本 FFF2 寫入協定，目標最高 5 fps，忙碌時跳到當下影格，避免累積過期畫面。iPixel 64×16 在原生模式、寫入通道足夠時，採 20 fps 單次 GIF；相容模式為橘色逐格點陣。其他尺寸略過開屏動畫，既有顯示功能不受影響。兩種屏幕的實際流暢度仍須裝置測試。

## 安裝

Android 直接覆蓋同簽章 APK，不要先刪除 App。iPhone 解壓完整 0.24 專案，執行 `xcodegen generate`，兩個 Target 沿用原開發團隊與 Bundle ID，再 Run；本次新增 AppIcon 與動畫素材，不能只換 Swift 檔。C4 不用更新。

驗證：兩平台共用 41 筆開屏狀態測試（一次播放、傳輸背壓、車況插入、取消、關屏／斷線、逾時），原車況重播、iPixel 封包與 LOY 96×16 封包尺寸檢查；資源逐檔相同、GIF 不循環且結尾為空白。編譯及模擬器結果由 GitHub Actions 記錄；實體屏幕及使用者裝置仍待驗證。
