# Carrot LED 方塊介面更新

Android 0.1.5 / iPhone 0.22。C4 橋接與金鑰沿用，更新手機 App 即可。

- 深色介面、琥珀色重點，首頁用醒目方框呈現最近送出的內容。
- 快捷分成「車況」「自訂文字」「眼睛動畫」，整張方塊可點選顯示。iPhone 兩欄，Android 依寬度排列；寬車機左側保留狀態及控制。
- 一顆電源鈕切換開關：開啟綠色、關閉黑色、未連線灰色。這是 App 指令狀態，不是屏幕電源讀回。
- 大型清屏鍵停止車況、自訂文字及眼睛動畫；重新開啟自動車況可恢復連動。
- 六種原創漸層眼睛：晶亮眨眼、靈動眼、惡魔眼、螺旋眼、火焰眼、機甲眼，可自行選色。iPixel 64×16 使用原生 GIF 循環播放（20 fps 素材）；其他尺寸／LOY 或關閉原生模式時，使用目標 5 fps 相容播放。實體流暢度待屏幕確認。
- 眼睛是獨立待機內容，不佔用五組自訂文字。車況提示優先，結束後恢復眼睛；自動車況開啟而 C4 資料失效時仍清屏。不連 C4 單獨測試眼睛，可先關閉「自動車況」。
- Android 預設開 App 自動啟動背景服務，首次需儲存 IP／金鑰並授權；設定頁可關閉自動啟動。iPhone 沿用開 App 自動重連與兩端就緒後啟動行車即時動態，背景設定可調整。
- 這是「開 App 自動開始」，不是開機自啟或強制關閉後自行復活。Android 每次最多 8 小時；iPhone 背景執行仍由系統管理。
- 字型、配色、五組自訂字詞與每項車況的獨立樣式均保留，編輯集中到「文字與動畫」。

安裝：Android 覆蓋安裝同簽章 APK；iPhone 解壓完整專案，執行 `xcodegen generate`，兩個 Target 選原開發團隊與 Bundle ID 後 Run。不需刪除舊 App。

驗證包含核心規則、眼睛優先切換／資料失效、點陣邊界與動畫、iPixel 封包、兩平台編譯，以及模擬器介面截圖。實體屏幕動畫、藍牙電源切換與特定車機背景限制需裝置確認。
