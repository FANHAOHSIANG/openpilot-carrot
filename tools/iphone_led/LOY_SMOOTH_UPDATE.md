# LOY 流暢動畫更新

Android 0.1.8（versionCode 9）／iPhone 0.25（App 與 extension build 25）。

## 本次改進

- LOY 眼睛與胡蘿蔔車開屏動畫由每 200 毫秒取樣，改成每 50 毫秒取樣，最高目標 20 fps。動畫以經過時間選格；傳輸忙碌時略過舊格，播放時間不因排隊拉長。
- 每個色層只傳送有像素的上下範圍，空白色層不傳送；每格仍先清屏，避免把透明像素誤當成擦除而殘影。沿用既有 FFF2 點陣協定與顏色，沒有加入尚未驗證的原生 GIF 上傳命令。
- LOY 封包最小傳送間隔由 20 毫秒縮為 5 毫秒。iPhone 保留系統的可寫入流量控制；Android 同時間只允許一筆寫入，等待回呼後才能續送。斷線時取消舊的排程。
- Android 快取已解碼的眼睛動畫，不再每格重新解碼 GIF。快取有上限，跨執行緒繪圖會序列化。
- C4 車況仍最多每 200 毫秒查詢一次；動畫加快不增加 C4 查詢頻率。車況、清屏、關屏、資料失效與開屏取消規則保留。已開始傳輸的畫面仍須送完，無法保證零切換延遲。
- iPixel 原生 GIF 及相容眼睛／開屏的播放頻率保留。原 LOY PLAY 96×16、八款眼睛、舊的配對與文字設定繼續使用。

這是軟體更新目標，不是實測屏幕 fps；手機、藍牙 MTU、控制板處理速度與背景限制都會影響結果。尚未在使用者實體 LOY 量測 20 fps、丟包及切換延遲。

## 安裝

Android 覆蓋安裝同簽章 0.1.8 APK，不要先刪 App。iPhone 下載完整 0.25 專案、執行 `xcodegen generate`，沿用原 Team／Bundle ID，再 Run。新增 `LoyBitmap.swift`，不能只換主 Swift 檔。C4 已有 LED 橋接者不需更新 C4。

停車後選擇 LOY PLAY、96×16，預覽眼睛與開屏；再按車況預覽、清屏及關屏確認切換。實體效果如有破圖或斷線，可保留設定並回報使用的 Android／iPhone、屏幕尺寸與動畫款式。

## 驗證

- Android：42 項核心檢查、291 筆車況情境、46 筆共用開屏狀態、iPixel 既有封包與眼睛測試，以及 2,204 次 LOY 裁切編碼／畫面還原／校驗碼檢查通過。
- 新增測試逐格重建 64×16 和 96×16 全部 48 格開屏的三個色層，包含空白、頂／底邊、非整數位元組寬度及多封包畫面；與原完整點陣相同。
- iPhone 對應編碼測試、完整 App／Live Activity 編譯及模擬器啟動由 GitHub Actions 驗證。
- APK 保留原測試簽章。下載檔的雜湊列在 [SHA256SUMS](downloads/SHA256SUMS)。裝置不會因 GitHub 更新而自動安裝。
